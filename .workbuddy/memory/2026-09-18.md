## 环境教训（本沙箱）
- PowerShell 工具不回传 stdout：写文件再 Read；bash PATH 损坏不可用；cmd.exe 被 PowerShell 工具拦截。
- **后台门禁运行时禁止编辑其读取的文件**（EBUSY + Edit 工具报成功但未落盘，基线 JSON 曾两次丢失写入）；编辑基线类文件用 Node 脚本 JSON 解析写回并立即回读验证。
- 删除文件被宿主 safe-delete 拦截（fail-closed），诊断临时文件统一移入 .workbuddy/tmp-diag/。
- vitest 5 无 `--reporter=basic`；PowerShell 文件名不能含冒号（NTFS ADS）。
- Read 工具以 GBK 显示 UTF-8 文件会产生假乱码（如 em-dash 显示为鈥），用 PowerShell 字节码验证后再判断。
