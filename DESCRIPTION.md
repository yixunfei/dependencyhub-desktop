# DependencyHub Desktop

DependencyHub Desktop is a cross-platform desktop workspace for multi-ecosystem project dependency management, toolchains, security health, and release governance. It supports npm, pip, Maven, Gradle, Cargo, Go Modules, Flutter pub, and C/C++ projects through a shared project context.

The platform combines dependency operations, package search, toolchain configuration, dependency health, security audits, supply-chain policies, release readiness, and plugin-oriented ecosystem extensions.

See [README.md](README.md) for the complete feature guide, screenshots, performance methodology, quick start, build commands, and release downloads.
